# Spec Delta

## Purpose

Даёт врачу просмотр оригинала клинической рекомендации прямо в приложении, чтобы любой вывод системы
можно было сверить с источником на нужной странице.

## ADDED Requirements

### Requirement: Просмотр оригинала клинрека

Интерфейс SHALL отображать оригинальный PDF выбранного клинрека постранично, не требуя скачивания файла
на устройство.

#### Scenario: Открытие клинрека на просмотр

- **WHEN** пользователь выбирает клинрек в библиотеке и открывает его
- **THEN** отображается первая страница оригинального PDF
- **AND** в шапке видны название клинрека, имя файла и версия документа

#### Scenario: Частичная загрузка файла

- **WHEN** просмотрщик запрашивает часть PDF-файла
- **THEN** сервер отдаёт запрошенный диапазон, и страница отображается без ожидания полной загрузки

### Requirement: Навигация по страницам

Интерфейс SHALL позволять переходить к предыдущей и следующей странице и MUST показывать текущую
страницу и общее число страниц.

#### Scenario: Переход вперёд

- **WHEN** пользователь запрашивает следующую страницу, и она существует
- **THEN** отображается следующая страница, и её номер показан как текущий

#### Scenario: Границы документа

- **WHEN** пользователь находится на первой или последней странице
- **THEN** переход за границу документа недоступен

### Requirement: Масштаб страницы

Интерфейс SHALL позволять изменять масштаб отображения страницы и MUST сохранять выбранный масштаб при
переходе между страницами.

#### Scenario: Увеличение масштаба

- **WHEN** пользователь увеличивает масштаб
- **THEN** страница отображается крупнее

#### Scenario: Масштаб при смене страницы

- **WHEN** пользователь переходит на другую страницу с изменённым масштабом
- **THEN** новая страница отображается в том же масштабе

### Requirement: Адресный переход к странице

Интерфейс SHALL принимать номер страницы в адресе просмотра и открывать документ сразу на ней, чтобы на
страницу можно было ссылаться извне.

#### Scenario: Ссылка на конкретную страницу

- **WHEN** пользователь открывает адрес просмотра с указанным номером страницы
- **THEN** документ открывается на этой странице

#### Scenario: Номер страницы вне документа

- **WHEN** в адресе указан номер, которого нет в документе
- **THEN** интерфейс не падает и показывает доступную страницу

### Requirement: Возврат в библиотеку

Интерфейс SHALL позволять вернуться из просмотра в библиотеку без потери применённого фильтра и
загруженных страниц списка.

#### Scenario: Возврат к списку

- **WHEN** пользователь возвращается из просмотра в библиотеку
- **THEN** открывается список клинреков в том состоянии, в котором пользователь его оставил

### Requirement: Отказ при недоступном PDF

Интерфейс SHALL показывать сообщение, когда PDF клинрека не найден на сервере или не может быть
разобран, и MUST NOT оставлять пустую область просмотра без объяснения.

#### Scenario: Файл не найден

- **WHEN** сервер отвечает `404` на запрос файла клинрека
- **THEN** интерфейс сообщает, что оригинал документа недоступен

#### Scenario: Повреждённый PDF

- **WHEN** полученный файл не удаётся разобрать как PDF
- **THEN** интерфейс сообщает о невозможности отобразить документ
