# Spec Delta

## MODIFIED Requirements

### Requirement: Состояния экрана библиотеки

Интерфейс SHALL различать загрузку данных, пустой результат и ошибку получения списка. Загрузка MUST
показываться заполнителем в форме будущих строк списка, а не пустой областью экрана.

#### Scenario: Список загружается

- **WHEN** запрос списка ещё не завершился
- **THEN** интерфейс показывает индикатор загрузки
- **AND** индикатор повторяет структуру будущих строк списка

#### Scenario: Ошибка получения списка

- **WHEN** запрос списка завершился ошибкой
- **THEN** интерфейс показывает сообщение об ошибке и способ повторить запрос
- **AND** пустой список при этом не показывается

#### Scenario: Данные сменили заполнитель

- **WHEN** список получен и показан
- **THEN** строки занимают место, подготовленное заполнителем
- **AND** содержимое экрана не скачет при появлении данных

### Requirement: Удаление клинрека из библиотеки

Интерфейс SHALL предлагать удаление клинрека из списка и MUST требовать подтверждение перед отправкой
запроса на сервер. Подтверждение SHALL показываться модальным диалогом. После успешного удаления клинрек
MUST исчезнуть из списка без перезагрузки страницы.

#### Scenario: Подтверждение удаления

- **WHEN** пользователь нажимает удаление у клинрека
- **THEN** интерфейс просит подтвердить удаление
- **AND** до подтверждения запрос на сервер не отправляется

#### Scenario: Отказ от удаления

- **WHEN** пользователь отменяет подтверждение
- **THEN** клинрек остаётся в списке, а данные не меняются

#### Scenario: Отмена с клавиатуры

- **WHEN** диалог подтверждения открыт и пользователь нажал Esc
- **THEN** диалог закрывается без отправки запроса
- **AND** фокус возвращается на кнопку удаления этого клинрека

#### Scenario: Удаление выполнено

- **WHEN** сервер подтвердил удаление
- **THEN** клинрек исчезает из списка библиотеки
- **AND** открыть его оригинал по прежней ссылке больше нельзя

#### Scenario: Удаление не удалось

- **WHEN** сервер отказал в удалении
- **THEN** интерфейс показывает причину отказа
- **AND** клинрек остаётся в списке

## ADDED Requirements

### Requirement: Доступ к загрузке клинрека

Интерфейс SHALL открывать форму загрузки по явному действию пользователя и MUST NOT постоянно занимать
ею область экрана, когда библиотека не пуста. При пустой библиотеке предложение загрузить PDF MUST быть
на месте списка.

#### Scenario: Кнопка загрузки в шапке

- **WHEN** библиотека не пуста и пользователь хочет загрузить PDF
- **THEN** форма загрузки открывается действием из шапки экрана
- **AND** до этого действия она не занимает место в списке

#### Scenario: Пустая библиотека предлагает загрузку

- **WHEN** в хранилище нет ни одного клинрека
- **THEN** предложение загрузить PDF показано на месте списка
- **AND** оно доступно без дополнительного нажатия

#### Scenario: Форма закрыта без загрузки

- **WHEN** пользователь открыл форму загрузки и закрыл её, не выбрав файл
- **THEN** запрос на сервер не отправляется
- **AND** список клинреков не меняется

### Requirement: Действия строки доступны без наведения

Интерфейс SHALL делать действия строки клинрека доступными при навигации с клавиатуры и на устройствах
без указателя, даже если в состоянии покоя они показаны компактно.

#### Scenario: Действия появляются при фокусе

- **WHEN** пользователь довёл клавиатурный фокус до строки клинрека
- **THEN** действия этой строки становятся видимыми
- **AND** их можно активировать клавиатурой

#### Scenario: Наведение не единственный способ

- **WHEN** устройство не поддерживает наведение указателем
- **THEN** действия строки доступны без него
- **AND** они не скрыты от пользователя
