# Spec Delta

## MODIFIED Requirements

### Requirement: Отказы внешних систем

Сервер SHALL различать недоступность векторного хранилища и отказ модели и MUST NOT показывать при этом ответ, не
подтверждённый фрагментами.

#### Scenario: Векторное хранилище недоступно

- **WHEN** поиск по фрагментам невозможен
- **THEN** сервер отвечает `503`, а интерфейс показывает причину и способ повторить запрос

#### Scenario: Модель недоступна или отказала

- **WHEN** провайдер LLM вернул ошибку, истёк таймаут или ответ не соответствует ожидаемой схеме
- **THEN** сервер отвечает `502` с причиной
- **AND** пользователю не показывается частичный или выдуманный ответ

#### Scenario: Сервис эмбеддингов недоступен при поиске

- **WHEN** поисковый запрос не удалось превратить в вектор: сервис эмбеддингов недоступен, отклонил ключ
  авторизации или отказал в доступе к модели
- **THEN** сервер отвечает `502` с причиной, называющей сервис эмбеддингов
- **AND** ответ не считается отказом «в документах нет ответа»
- **AND** пользователю не показывается ответ, не подтверждённый фрагментами
