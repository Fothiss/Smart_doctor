# Локальные модели эмбеддингов

Сюда кладутся файлы модели эмбеддингов. Содержимое папки в git не попадает: веса
весят гигабайты, а индексация работает офлайн — из этой папки, без обращения к Hugging Face.

## Что положить

```
ml_models/
+-- Qwen3-Embedding-0.6B/         <-- имя должно совпадать с EMBEDDING_MODEL_PATH
    +-- config.json               <-- обязателен
    +-- tokenizer_config.json     <-- обязателен
    +-- model.safetensors         <-- или pytorch_model.bin
    +-- tokenizer.json
    +-- vocab.json, merges.txt
    +-- special_tokens_map.json
```

Обязательные файлы проверяются при первой индексации: без `config.json` или
`tokenizer_config.json`, либо без весов, клинрек переходит в `failed` с понятной причиной.

## Что важно знать

- **Модель декодерная.** `Qwen3-Embedding-0.6B` — это `Qwen3ForCausalLM`: вектор берётся
  с последнего токена, паддинг слева, а инструкция добавляется только поисковому запросу.
  Код задаёт это явно и не полагается на конфигурацию папки: неполный снапшот иначе
  приводит к усреднению по токенам и молча неверным векторам.
- **Размерность.** 1024. Она входит в имя коллекции Qdrant
  (`guideline_chunks__1024`), поэтому смена модели на другую размерность не смешивает
  векторы, но требует полной переиндексации.
- **Смена модели.** Идентификатор модели пишется в метаданные клинрека при индексации.
  После замены модели клинреки нужно переиндексировать — по одному, через
  `POST /api/guidelines/{guideline_id}/index`.

## Пути и переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ML_MODELS_DIR` | `ml_models` | каталог с папками моделей (относительно `backend/`) |
| `EMBEDDING_MODEL_PATH` | `Qwen3-Embedding-0.6B` | папка модели внутри `ML_MODELS_DIR` |
| `EMBEDDING_MODEL` | `Qwen/Qwen3-Embedding-0.6B` | идентификатор модели для метаданных |
| `EMBEDDING_DIM` | `1024` | размерность вектора |
| `EMBEDDING_MAX_SEQ_LENGTH` | `512` | предел длины входа |
| `EMBEDDING_BATCH_SIZE` | `16` | сколько чанков кодируется за проход |
| `EMBEDDING_THREADS` | `4` | потоки инференса |
